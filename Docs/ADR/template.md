# NNNN. Título corto de la decisión

**Estado:** Propuesto

## Contexto

¿Qué problema o necesidad motiva esta decisión? ¿Qué restricciones existen (técnicas, de plataforma, de plazo)?

## Decisión

¿Qué se decidió hacer, en concreto?

## Alternativas consideradas

¿Qué otras opciones se evaluaron y por qué se descartaron?

## Consecuencias

¿Qué mejora, qué empeora o queda pendiente como consecuencia de esta decisión?
